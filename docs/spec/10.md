## 10. UI/UX 與美術

地圖由 Phaser 繪製，所有面板、文字與表單改用 DOM
疊加層，以取得文字縮放、無障礙與較快的開發速度。

主要設計尺寸 390×844 CSS px，另驗證 360×740、430×932 與桌面。版面：頂部
8--10%（地名、季節、速度、最多 3 個狀態，其中之一固定為支持度）；地圖
68--76%；底部 12--18%（建設、提案、家族、世界、歷史）。

介面分兩種模式：**觀察模式**預設追蹤玩家家族，也可追蹤其他人物、查看動作與故事；**管理模式**用於政策、財政、建設與歷史。

  ------------------------------------------------------------------------------------------------------
  畫面         核心操作                                           錯誤／空狀態
  ------------ -------------------------------------------------- --------------------------------------
  主地圖       拖曳、縮放、點選、追蹤人物                         無可選目標時顯示說明

  建設         選類型→格線預覽→成本與可達性→確認                  材料不足、阻擋道路、預算不足

  提案／政策   提案人、理由、成本、副作用→批准／延後／拒絕        無提案時顯示目前村況

  家族         家長個人選擇、繼承人候選、家族帳戶、支持度與原因   無待決選擇時顯示家族近況

  人物         工作、關係、需求、計畫、生涯                       失業或無住所時說明原因

  經濟         供需、價格趨勢、企業帳務                           無成交時顯示瓶頸

  歷史         時間軸、歷任領袖、人物、地圖對照                   無重大事件時顯示日常摘要

  改選         查看候選人、支持度原因、確認參選                   落選後說明玩家轉為村民及下次改選時間

  繼任         確認繼任人選、切換控制的家長                       家族斷絕時選擇另一家族或封存紀錄
  ------------------------------------------------------------------------------------------------------

觸控區至少 44×44 CSS
px；建設支援撤銷；可關閉動畫、調整文字大小。玩家先看到自然語言摘要，再按需查看精確帳務。

**美術規格（獨立文件）**：16px 地形格、建築
footprint、角色方向與動畫幀、圖層排序、季節色票、UI 字體；所有素材須在
360×740 真機上測試辨識度。

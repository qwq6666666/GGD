## 4. 地圖、尋路與細節層級

V1 只模擬一個核心聚落：地圖 96×96 格，初期可建區 48×48，以 16×16
區塊管理；地形 tile 為 16×16 px。

-   **地形欄位**：tile_id、height_class、soil、forest、water、buildable、walk_cost。

-   **建築佔地**：footprint 與出入口格；放置時驗證可達性、坡度與碰撞。

-   **尋路**：A\*，同分路徑以格座標 ID
    決定性排序（tie-break）；道路圖分層並批次快取，道路或橋梁變動時使相關快取失效；不逐幀為所有
    NPC 尋路。

-   **細節層級（LOD）**：只有單一權威世界狀態與單一日步進。縮放只改變渲染細節（逐人動畫
    ↔ 群集圖示），不是兩套模擬，因此不存在「近遠景切換」的守恆問題。

-   **區域特色**：農業、森林、礦區、河港由地形資源與交通成本自然形成，不使用固定升級樹。

地圖外的世界以 2 個「貿易節點」表示（見 7.5），V1 不模擬節點內的 NPC。

## 17. 風險

  ---------------------------------------------------------------------------------------------------
  風險                       預防措施
  -------------------------- ------------------------------------------------------------------------
  玩法空洞                   A3 先驗證 15 分鐘切片；以提案與玩家家族作為主動詞與敘事鉤子

  經濟過於寬裕或死鎖         以邊際報酬與勞動市場自我調節；冬季存糧張力；救濟與節點採購作為恢復路徑

  NPC 抖動                   計畫慣性、冷卻、需求硬約束

  決定性破裂                 整數／定點運算、禁用 API 的 lint 規則、CI 回放測試

  存檔膨脹                   帳本彙總、分級保留、100 年壓測

  手機卡頓                   Worker、SoA、分時決策、視野剔除、路徑快取

  AI 實作偏離規格            單一規格、CLAUDE.md、任務卡、受保護測試、階段末比對

  AI 產生的程式無人真正理解  開發者審查每個 diff；核心模組（帳本、排程、PRNG）由開發者親自理解並寫
                             ADR

  範圍失控                   階段門檻、附錄 B 延後清單、未通過不得新增系統
  ---------------------------------------------------------------------------------------------------

模擬校準）。

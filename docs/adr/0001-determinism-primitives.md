# ADR-0001：決定性基礎模組

- 狀態：已採用（A0）
- 依據：GDD 11.3

## 決策
- PRNG 採 sfc32，以 splitmix32 展開種子；只用 `Math.imul` 與位元運算。狀態 4×uint32 存於世界。
- 定點數尺度統一 `FX = 1000`；所有除法經 `idiv`（floor），禁止散落的 `Math.round`。
- 狀態 hash：鍵排序的正規化 JSON → 64 位元雙通道雜湊（16 位 hex）。正規化同時拒絕浮點數與非純物件，作為「狀態只含整數」的不變量。
- 機率以 0..65536 表示。

## 影響
- PRNG 序列以快照測試鎖定；變更會破壞舊存檔重播，需遞增 `SIM_VERSION` 並寫遷移。

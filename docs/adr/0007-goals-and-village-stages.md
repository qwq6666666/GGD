# ADR-0007：村級目標與階段、可建區擴張、提案滑動

**背景**：試玩感覺「只有批提案」，缺少建村感與中期方向。GDD v3.1 沒有目標系統。

**決定**
- 世界狀態新增 `progress { stage, done[] }` 與 `map.zmin/zmax`（可建區）。存檔 schema v3，附 v2→v3 遷移與測試（不損失資料，從「營地」起算）。
- 階段：營地（48 格）→ 村（56）→ 大村（68）→ 鎮（84）→ 繁榮之鎮。每階段 3 個選項式目標，達成任意 2 項升階。目標與解鎖表在 `packages/content/src/goals.json`。
- 目標條件只讀世界狀態（建築數、路格數、人口、存糧、支持度、企業數、日期），無隨機、已達成者永久記錄。
- 解鎖：學堂、診所、商業用地（村）；石路、石橋（大村）。玩家命令未解鎖時回 `locked`；居民提案不受限。
- 步進：在每日末新增 `updateProgress`（偏離 GDD 3.1 固定順序，位於所有模擬步驟之後，不影響既有計算）。
- 目標與階段不給金錢獎勵，避免破壞貨幣守恆與已校準的平衡。
- 提案改為一次一張的卡片：右滑核准、左滑拒絕，卡片列出公庫與材料的消耗、庫存缺口與信任變化；按鈕保留作為無障礙備援。

**未做**：「拓荒開局」的完整形式（開局只有營地、所有建築由玩家蓋）。開局目前保有 6 戶與 7 家企業，營地階段的目標扮演拓荒引導。完整版需動初始狀態並重新校準，建議等機器人試玩能量化後再做。

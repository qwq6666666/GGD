# ADR-0008：電腦自動模式

**背景**：玩家希望有「電腦自動玩」的按鈕，放鬆觀察、或在忙碌時讓村子照常運作。

**決定**
- 規劃邏輯在 `packages/sim/src/auto.ts` 的 `planAuto(world)`：純函式、只讀世界狀態、無隨機，回傳建議行動清單。
- 開關是 Worker 排程層旗標（同速度，不進世界狀態）。開啟後每週最後一日規劃一次，之後**每天最多送出一項命令**（避免同日世界版本衝突）。命令與玩家命令走同一條路並寫入命令日誌，所以存檔回放一致。
- 行動：核准付得起且材料夠的提案（否則延後）、春荒前採購糧食、學堂診所啟用後編列預算、支持度過低時降收成稅、朝目前階段目標建設（農田、鋪路、學堂、公共住宅、石路、診所、商業用地）。
- 保留 1200 文公庫儲備；一次只開一項新工程。
- 玩家隨時可手動操作；換新遊戲時自動關閉。不是領袖時只會嘗試參選。

**實測（模擬）**：自動 12 年，4 個種子皆在第 2 年升到「村」，2 個在第 8 到 11 年升到「大村」；公庫常接近見底，人口停在約 30。這是自動策略偏保守加上人口平衡尚未校準的結果，不代表最佳玩法。

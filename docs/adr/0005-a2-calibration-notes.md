# ADR-0005：A2 經濟校準紀錄與已知偏差

- 狀態：已採用（A2）；所有數值仍標記待校準（`packages/content/src/economy.json`）

## 校準結果（headless，8 個種子 × 12 年，無玩家介入）
- 8/8 種子聚落未滅絕；人口落在 15–29；貨幣與商品守恆（逐日檢查，每 30 日做完整一致性檢查）。
- 生長季非自願失業約 14%（GDD 目標 < 10%）。原因：7.8 勞力預算本來就有約 1,400 人日的閒置勞力，需由公共工程與預算吸收。
  測試門檻暫設 15%，玩家以公共工程補足後預期可 < 10%。

## 為使閉環可存活而做的調整（皆在 content 內）
1. 農田產能 500 → 750 人／季（GDD 假設 500；加入通勤損耗、肥力與工具係數後，500 使聚落在第 2–3 年必然餓死）。
2. 基準價：工具 60 → 120、家具 90 → 150（否則工坊邊際產值低於工資，產業鏈無法存活）。
3. 起始工資 20 → 30、最低工資 20（工資必須足以買得起糧食）。
4. 工具改由「家庭」購買（符合 7.1 需求層級第 4 層），無工具係數 0.7 → 0.9。
5. 工具工坊、家具工坊、採石場開局為公有，由公共帳戶提供週轉資金（私人業主資本不足會讓產業鏈死鎖）。
6. 新增三個安全網：常平倉（公共帳戶在糧價不高時買糧）、以工代賑（公共雜役，工資取最低生活費，可由 `workRelief` 政策關閉）、採集漁獲（無業成年人每日覓食）。
7. 收成稅預設 5% → 10%；商業稅 3% → 6%。
8. 出生需人均存糧 ≥ 20 日。

## 與 GDD 的偏差（待開發者確認）
- 上述 1–8 皆偏離 GDD 18 章的初始假設，但都屬「待校準」範圍。
- 新增政策 `workRelief`、新增命令 `StandForElection`／`SwitchFamily`／`OrderImport`（GDD 11.2 命令清單未列）。

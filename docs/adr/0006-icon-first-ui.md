# ADR-0006：圖示優先、細節摺疊的介面

**背景**：試玩回饋「文字太多」。手機直式畫面一次放太多說明句與欄位。

**決定**
- 數字＋圖示標籤（`tag()`）取代句子；成本一律 `🪙 🪵 🪨 👷`，商品用 `COM_ICON`。
- 次要說明收進 `more()` 摺疊（ⓘ），預設收合；提案只留原因一行與 ✔ ⏳ ✖ 三鍵。
- 頂欄 3 個摘要（👥 支持度、🌾 存糧日、💰 公庫）；底部導覽與分頁改圖示＋短標。
- 支持度改大儀表，只列最差 3 項因子；居民卡改 🍞 ❤ 😊 三條。
- 教學與提示縮成一行；toast 加圖示並縮短。
- 所有純圖示按鈕都有 `aria-label`，維持螢幕閱讀器可用。

**取捨**：圖示依賴系統 emoji 字型，各平台樣式不同；若日後要統一，改為自繪 SVG 圖示集（只需替換 `tag()` 與 `*_ICON` 表）。
